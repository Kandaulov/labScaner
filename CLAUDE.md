# labScaner — контекст для ИИ-ассистента

> Этот файл читается ИИ первым. Здесь — суть проекта, правила работы и карта документации.
> Подробности — в `docs/`. Если факт здесь расходится с `docs/DECISIONS.md`, прав `DECISIONS.md`.

## Что строим (в одном абзаце)

Веб-система для преподавателей вуза (несколько пользователей, у каждого свои предметы, почта и Диск). Она забирает письма студентов из почтового ящика (IMAP),
распознаёт по **теме письма** (`{Группа} – {Предмет} – {ФИО} – Лаб №{N}`) группу, предмет, студента и работу, складывает вложения (PDF/DOCX)
на **Яндекс Диск** в структуру папок, прогоняет работу через **LLM** на соответствие заданию и
записывает результат в **журнал** группы. Преподаватель в защищённом паролем веб-интерфейсе
смотрит журнал, правит/подтверждает оценки и замечания и по флажку «отправить уведомление»
отправляет студенту письмо с результатом по каждой работе.

**Главный принцип:** ИИ — помощник-аудитор, а не экзаменатор. Ничего не уходит студенту без
подтверждения преподавателя.

## Стек (зафиксирован, см. ADR в `docs/DECISIONS.md`)

- **Backend:** .NET 10 (LTS), ASP.NET Core, EF Core + Npgsql
- **БД:** PostgreSQL 17
- **Фоновые задачи:** Hangfire (хранилище в PostgreSQL) — без Redis
- **Почта:** MailKit (IMAP приём, SMTP отправка)
- **Файлы:** Яндекс Диск REST API (OAuth, доступ ко всему Диску — работы кладутся в существующие папки преподавателя)
- **Извлечение текста:** DocumentFormat.OpenXml (DOCX), UglyToad.PdfPig (PDF)
- **LLM:** `ILlmClient` поверх OpenAI-совместимого API; по умолчанию Timeweb Cloud AI Gateway (VPS тоже на Timeweb)
- **UI:** Razor Pages + htmx (+ Alpine.js точечно), без SPA-сборки
- **Тесты:** xUnit, Testcontainers (PostgreSQL), Playwright (E2E)
- **Развёртывание:** Docker Compose на VPS Timeweb Cloud (Россия), Caddy (HTTPS), GitHub Actions → GHCR

## Роли в работе над проектом

- **architect** — модель данных, границы модулей, ADR, ревью решений. Код не пишет.
- **developer** — реализация по задаче из ROADMAP, с тестами, в рамках принятых ADR.

## Правила для кода

- Язык интерфейса, писем и комментариев к доменной логике — **русский**. Идентификаторы в коде — английские.
- Доменные термины в коде: `Subject` (предмет), `Group`, `Student`, `Assignment` (работа: лаб/курсовая),
  `Submission` (сдача), `SubmissionFile`, `AiCheck` (проверка LLM), `Review` (решение преподавателя),
  `FinalAssessment` (итоговая аттестация), `InboxMessage` (сырое письмо),
  `Term` (учебный семестр с календарём: зачётная неделя, сессия),
  `SubjectTerm` (предмет в семестре: группы, корневая папка на Диске, набор работ, дедлайны).
- Предметы сейчас: **КорпИС**, **ОС**, **СПП**. У каждого — свой набор лабораторных. Задания: один DOCX
  на все лабы (делится по заголовкам «Лабораторная работа №N») + один DOCX на курсовую.
- На Диске внутри папки семестра — папки `{Группа} - ЛР` и `{Группа} - Кр` на каждую группу.
- «В срок» = преподаватель принял работу до дедлайна. Все лабы в срок + курсовая в срок (если она есть
  в предмете) → претендент на автомат («зачтено» / «5»).
- Данные преподавателя изолированы глобальным фильтром по `teacher_id`; группы, студенты, календарь
  и настройки LLM — общие (ADR-016).
- Три журнала: событий (что сделано и что ждёт преподавателя), проверки работы (ход конвейера),
  группы (оценки + история комментариев).
- Каждое входящее письмо обрабатывается **идемпотентно** по `Message-ID`: повторный прогон не создаёт дублей.
- Внешние сервисы (IMAP, SMTP, Яндекс Диск, LLM) — только через интерфейсы; в тестах — фейки.
- Секреты — только в переменных окружения / user-secrets. Никаких токенов в репозитории.
- Персональные данные студентов не отправляются в LLM: перед проверкой ФИО и e-mail вырезаются из текста.
- Миграции БД — EF Core migrations, в репозитории.
- Commit-сообщения на русском, в повелительном наклонении: «Добавить разбор темы письма».

## Чего НЕ делать

- Не отправлять письма студентам автоматически, минуя подтверждение преподавателя.
- Не выставлять итоговые оценки (курсовая, экзамен, зачёт) автоматически — только вручную.
  Автомат система только *предлагает*, ставит преподаватель.
- Не удалять, не переименовывать и не перезаписывать ничего на Яндекс Диске преподавателя.
- Не тащить SPA-фреймворк и Redis без ADR.
