Этапы идут по порядку; внутри этапа задачи можно параллелить.
Каждый этап заканчивается работающим, проверяемым результатом.

- [x] Архитектура, стек, ADR
- [x] Роли агентов (архитектор, разработчик, тестировщик)
- [x] Промт для Claude Design
- [x] Формат темы письма, предметы, хранилище, дедлайны (ADR-010…013)

- [ ] Репозиторий на GitHub, ветка `main` защищена, шаблон PR

**Готово, когда:** открытые вопросы закрыты, репозиторий создан.
